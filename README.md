# KoreDeFilter

改行区切りのリストを貼り付けて、Excelの表をまとめて絞り込むアドインです。

別のシートからコピーした商品名や管理番号などを、オートフィルタの条件として使えます。入力した値が対象の表にあるかも確認できます。

## 使用例

次の表の「品名」を絞り込む場合:

| 品名 | 数量 |
|---|---:|
| りんご | 10 |
| みかん | 5 |
| ぶどう | 8 |
| りんご | 3 |

KoreDeFilterに次のリストを貼り付けます。

```text
りんご
みかん
```

「品名」列のセルを選んでフィルタを実行すると、りんごとみかんの行が表示されます。りんごのように同じ値が複数行にあれば、その行もまとめて残ります。

## 主な機能

- 改行区切りの複数の値で、選択した列を絞り込みます。
- 通常のオートフィルタと、Excelのテーブルに対応します。
- テーブルが複数ある場合は、選択したセルが属するテーブルを対象にします。
- 入力した条件の重複を除外します。
- 入力した値がすべて見つかれば通知し、一部が見つからなければ「ある／ない」の一覧をメモ帳に出力します。
- 該当する表示行がない場合は、メッセージを表示して実行した列のフィルタ条件を解除します。

## 動作環境

- Windows版のデスクトップExcel
- VBAマクロを実行できる環境
- 結果出力に使用するWindowsのメモ帳

Windowsの機能を利用するアドインです。Excel for the webやMac版Excelは対象にしていません。Excelのバージョン別・32bit/64bit別の動作確認一覧は、現在用意していません。

## インストール

1. このリポジトリをダウンロードして展開します。GitHubの **Code → Download ZIP**、または `git clone` を利用できます。
2. 作業中のブックを保存し、Excelを終了します。
3. `bin` フォルダの [install_KoredeFilter.vbs](bin/install_KoredeFilter.vbs) を実行します。
4. 確認メッセージでインストールを選びます。
5. Excelを起動し、リボンに **KoreDeFilter** タブが表示されることを確認します。

インストーラーと [KoreDeFilter.xlam](bin/KoreDeFilter.xlam) は、同じフォルダに置いてください。インストーラーは次の場所にアドインをコピーし、Excelへ登録します。同名のファイルがある場合は上書きします。

```text
%APPDATA%\Microsoft\AddIns\KoreDeFilter.xlam
```

VBScriptを実行できない環境では、`KoreDeFilter.xlam` を上記のフォルダにコピーし、Excelの「Excelアドイン」の設定からファイルを参照して有効にしてください。マクロの実行可否は、利用環境のセキュリティ設定に従います。

## 使い方

1. 対象の表に見出し行を用意し、オートフィルタを設定するか、Excelのテーブルにします。
2. **KoreDeFilter** タブからツールを開きます。
3. 入力欄に、条件となる値を1行に1つずつ貼り付けます。Excelの1列からコピーした値も使えます。
4. **対象の表の中で、絞り込みたい列のセルを選択します。**
5. フォームのフィルタ実行ボタンを押します。

フォームを開いたまま、Excel側のセルやシートを操作できます。実行時に選択しているブック・シート・列が対象になるため、実行前に選択位置を確認してください。

### 入力の整理

「重複と空白削除」ボタンで、貼り付けたリストから重複と空行を取り除けます。フィルタの実行時にも重複を除外しますが、公開版では空行が条件に残る場合があるため、実行前に入力を整理してください。

### 結果の見方

| 結果 | 動作 |
|---|---|
| 入力した値がすべてある | フィルタを適用し、件数を短時間表示します |
| 一部の値がない | フィルタを適用し、「ない」「ある」と各条件の判定をメモ帳に出力します |
| 表示されるデータ行がない | メッセージを表示し、実行した列のフィルタ条件を解除します |

「ある／ない」は、対象表の非表示行も含めて判定します。他の列にもフィルタがかかっている場合、「ある」と判定された値でも、画面上に表示されるとは限りません。

日付を条件にするときは、対象セルの表示形式に合わせた文字列を入力してください。

### フィルタの解除

フォームのフィルタ解除ボタン、またはExcel標準のフィルタ操作で解除できます。複数テーブルがあるシートでの解除ボタンの動作は確認中です。解除されない場合は、Excel側で対象テーブルの条件をクリアしてください。

## 注意点・既知の課題

- **対象表の中のセルを選んで実行してください。** 通常のオートフィルタ範囲の左右にあるセルを選ぶと、エラーになる場合があります。
- メモ帳への出力は、起動タイミングやウィンドウ名に依存します。現在の実装は「無題 - メモ帳」というタイトルを使用しており、環境によって出力に失敗する場合があります。
- メモ帳への出力時は、結果をクリップボードにコピーします。それまでのクリップボードの内容は置き換わります。
- 公開版には、条件行の前後のスペースが取り除かれない問題と、空行がフィルタ条件に残る問題があります。前後のスペースを除き、空行のないリストで実行してください。
- 入力内容はアドイン内のシートに保持されます。Excelの再起動後まで残ることは保証していません。アドインを保存した場合は、その時点の入力内容もファイルに残ります。
- 半角スペースだけの入力、空の状態での「重複と空白削除」、表の先頭列を非表示にした場合は、追加の検証が必要です。

不具合を報告する際は、ExcelとWindowsのバージョン、通常範囲かテーブルか、表の開始位置、入力例、期待する結果と実際の結果を添えて [Issues](https://github.com/matan-z/KoreDeFilter/issues) にお知らせください。

### 開発中の改善

次の改善を開発中です。現在の公開版には、まだ含まれていません。

- 条件行の前後にある半角・全角スペースとタブの除去
- フィルタ実行時の空行除外と、条件が空になった場合のチェック
- 通常範囲、複数テーブル、日付、空白・空行などを確認する自動テスト

## アンインストール

作業中のブックを保存してExcelを終了し、[uninstall_KoredeFilter.vbs](bin/uninstall_KoredeFilter.vbs) を実行します。確認メッセージでアンインストールを選ぶと、Excelのアドイン登録を解除します。

このスクリプトは `.xlam` ファイルを削除しません。ファイルも削除する場合は、登録解除後にExcelを終了し、インストール先の `KoreDeFilter.xlam` を削除してください。

## 開発

VBAソースをテキストファイルとして管理し、PowerShellスクリプトでExcelとの間を同期します。

### リポジトリの構成

```text
bin/
  KoreDeFilter.xlam            配布用アドイン
  install_KoredeFilter.vbs     インストーラー
  uninstall_KoredeFilter.vbs   登録解除スクリプト
src/KoreDeFilter.xlam/
  m_FilteringByArray.bas       起動・対象表の選択
  c_FilteringByArray.cls       入力整形・フィルタ・存在判定
  f_FilterTool.frm             フォームの定義とコード
  f_FilterTool.frx             フォームのバイナリデータ
  ThisWorkbook.bas            ブックのコード
  Sheet1.bas                  シートのコード
tools/
  vba-sync.ps1                VBAの書出し・取込み
.vscode/
  tasks.json                  同期用タスク
LICENSE
```

### 準備

- Windows PowerShell（`powershell.exe`）を使用します。
- アドインをインストールし、Excelで読み込める状態にします。
- ソース同期のために、Excelのトラストセンターで **「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」** を有効にします。
- VSCodeで作業する場合は、Gitリポジトリのルートフォルダを開きます。

編集対象は `src/KoreDeFilter.xlam/` です。インストール先の `AddIns` フォルダに古いソースや同期スクリプトが残っている場合も、リポジトリ側を作業元として統一してください。

### ソースを編集して反映する

リポジトリのルートで実行します。

```powershell
# src のコードを、Excelで開いているアドインへ反映
powershell.exe -NoProfile -File .\tools\vba-sync.ps1 -Action Import

# Excelで動作を確認してから、保存と配布用コピーの更新を実行
powershell.exe -NoProfile -File .\tools\vba-sync.ps1 -Action Import -Save
```

`Import` のみではアドインを保存しません。`-Save` を付けると、インストール先の `backups` フォルダに保存前のファイルを退避し、アドインを保存して `bin` へコピーします。

ExcelのVBE側で編集した内容をソースへ書き出す場合は、先にアドインを保存してから実行してください。`Export` はコードを書き出すとともに、ディスク上のアドインを `bin` へコピーします。

```powershell
powershell.exe -NoProfile -File .\tools\vba-sync.ps1 -Action Export
```

VSCodeでは同じ操作を **VBA: Import**、**VBA: Import & Save**、**VBA: Export (Excel → VSCode)** のタスクから実行できます。

### 同期時の制約

- VBAのテキストファイルはUTF-8 BOM付き・CRLFで管理します。`.vbs` はShift-JISのまま扱います。
- 既存コンポーネントへの `Import` はコード部分を置き換えます。フォームのデザインや属性行の変更は反映しません。
- 新しい `.bas`・`.cls` は追加できます。新規フォームはVBEで作成し、`Export` で `.frm` と `.frx` を書き出してください。
- フォームのデザインを変更した場合は、`.frm` と `.frx` の両方を管理します。

### 動作確認

自動テストスクリプトは未公開です。変更時は、テスト用のブックで次の動作を確認してください。

- 通常範囲とテーブルの両方で、指定した値の行が表示されること
- 表がA1以外から始まる場合や、テーブルが複数ある場合も、対象が正しいこと
- 条件がすべて存在する場合、一部が存在しない場合、該当行がない場合の表示
- 日付の表示形式に合わせた条件でのフィルタと存在判定
- フィルタの解除と、実際のメモ帳・クリップボードへの出力
